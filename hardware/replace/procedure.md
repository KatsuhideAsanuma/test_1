# HP Z4 G4 部品交換手順書

作成日: 2026-10-14（JST）　改訂: 2026-10-14（対象をCPUとSSDの2点に絞った）
対象機: HP Z4 G4 Workstation / 基板 81C5 / Intel C422 / BIOS P61 v02.97

| 区分 | 現在 | 交換後 | 判定 |
|---|---|---|---|
| CPU | Xeon W-2123 (4C/8T, 120W) | Xeon W-2235 SRGVA (6C/12T, 130W) | 可。現行クーラーのまま |
| SSD | Samsung 512GB NVMe（維持） | WD Blue SN5100 2TB を2基目のM.2へ追加 | 可 |
| GPU | Quadro P2000（維持） | 変更なし。RTX 3090は別機へ | 対象外 |
| メモリ | 8GB×4（維持） | 変更なし | 対象外。ラベル確認のみ |

関連ファイル: [precheck.md](precheck.md)（開封時記入シート）、[parts.json](parts.json)（部品データ）、[source-excerpts.md](source-excerpts.md)（根拠原文）、[verify-after.sh](verify-after.sh)（事後確認）。
保守マニュアルのページは「印刷p / PDFp」で併記する（PDF = 印刷 + 8）。

---

## 0. 作業方針

1. **CPU → SSD の順に1部品ずつ。** CPU交換後に起動確認を取ってからSSDを追加する。問題発生時に原因を切り分けやすい。
2. **記録を残す。** 作業前後で `verify-after.sh` を実行し、`../observations.json` と `../upgrade-reference.*` を更新する。
3. **買い足しはグリスだけ。** 電源・カードガイド・DIMMは今回不要。

## 1. 開封前の準備（OS側）

1. **バックアップ。** 現在のrootはLUKS暗号化LVM（`dm_crypt-0` → `ubuntu-vg/ubuntu-lv`）上にある。重要データを外部へ退避する。
2. **基準値の取得。** `bash hardware/replace/verify-after.sh` を実行し、出力を `before-<日付>.txt` にリネームして残す。
3. **管理者権限で取れる情報（任意だが推奨）。**
   ```
   sudo dmidecode -t 17 > hardware/replace/dmidecode-t17-before.txt
   ```
   DIMM の Part Number / Speed / Configured Memory Speed / Type Detail (Registered) が分かる。交換後の比較に使う。
4. **BIOSの確認。** P61 v02.97 はW-2200対応済み。これより新しい版がHPサポートに出ていれば先に適用する。
5. **マイクロコード。** `dpkg -l intel-microcode` で Ubuntu の `intel-microcode` が入っていることを確認する。W-2235 はCPUID 06_55h stepping 7。

## 2. 開封確認と判定

[precheck.md](precheck.md) を印刷し、サイドパネルを開けて記入する。
開け方: 保守マニュアル 印刷p19/PDFp27（分解準備）、p22/PDFp30（アクセスパネル）。
シャットダウン → 電源コードを抜く → 外部機器を外す → 左側面を手前にしてラッチを上げ、パネル上端を手前に倒して持ち上げる。

| 確認項目 | 結果 | 判定 |
|---|---|---|
| ヒートシンクファン | 5線 | 140W以下クラス。W-2235（130W）に使用可 |
| ヒートシンクファン | 6線 | 140W超クラス。そのまま使用可 |
| DIMM速度表記 | 2933 または 3200 | そのまま使用 |
| DIMM速度表記 | 2666（HP純正1XD8xAA系） | HPの表ではW-2200非対応。交換後に容量32GB・速度を確認し、異常があれば4章17項へ |
| M.2 2基目 | ネジ・スタンドオフあり | 可 |
| M.2 2基目 | なし | M.2用ネジ（M2×3mm程度）とスタンドオフを用意してから作業 |

## 3. 共通の分解準備

1. 静電対策（リストストラップ、または金属筐体に触れて放電）。
2. 外したケーブルにはラベルを付け、ネジは部品ごとに分けて保管する（保守マニュアル p19/PDFp27 の注記）。
3. 作業中は電源コードを抜いたままにする。コードが刺さっている限り基板に電圧がかかる。

## 4. 手順A: CPU交換（W-2123 → W-2235）

根拠: 保守マニュアル p31–33 / PDFp39–41。工具: T30トルクスドライバー、サーマルグリス、無水エタノールと不織布。

### 取り外し

1. ヒートシンクのファンケーブルを基板から外す。
2. ヒートシンク上のラベルに書かれた順序で、4本のT30キャプティブネジを緩める。**対角（X字）順**で少しずつ均等に緩める。ソケットのピンは脆く、曲げると基板交換になる。
3. ヒートシンクを持ち上げる。**CPUはヒートシンク底面に付いたまま**外れる構造なので、ヒートシンクを裏返し、CPUを上にして置く。
4. ヒートシンク裏面のプロセッサホルダーを固定する4つのクリップを外し、ホルダーを真上に持ち上げる。
5. ホルダーのクリップを慎重に開き、W-2123 を真上に持ち上げて取り出す。静電袋に入れて保管する。
6. ヒートシンク底面の古いグリスを完全に拭き取る。

### 取り付け

7. W-2235 の**三角マーク**をホルダーの三角マークに合わせ、CPU側面のノッチをホルダークリップのリブに合わせて装着する。
8. ヒートシンク底面にグリスを塗布する。
9. ホルダーの三角マークをヒートシンクの三角マークに合わせてホルダーを装着し、クリップ4つを掛ける。
10. ソケットのピンに触れないよう、ヒートシンク（CPU付き）をソケット上に垂直に降ろす。
11. ラベルの順序でT30ネジを対角に少しずつ締める。
12. ファンケーブルを基板に接続する。

### 初回起動

13. アクセスパネルを戻し、電源コードを接続して起動する。
14. POSTでエラーが出た場合: **008**（BIOS未対応）→ BIOS版を確認。**912**（クーラー不一致）→ 140W超クラスのヒートシンクに交換。詳細は保守マニュアル p77/PDFp85、p82/PDFp90。
15. F10 で Computer Setup に入り、CPU名、メモリ容量、メモリ速度を確認する。
16. OS起動後 `bash hardware/replace/verify-after.sh` を実行し、CPU が `W-2235` 6コア/12スレッドで認識され、メモリが32GB（4枚）のままであることを確認する。
17. `sudo dmidecode -t 17 | grep -E 'Speed'` で Configured Memory Speed を確認する。2666表記DIMMで起動しない、または容量が減る場合は、DIMMの座り直し → それでも駄目ならW-2123に戻して再現性を確認し、必要ならHP純正2933品（5YZ56AA 8GB、両世代対応）への交換を検討する。

## 5. 手順B: M.2 SSD追加（WD Blue SN5100 2TB）

根拠: QuickSpecs p6・p22、BIOS設定は保守マニュアル p67/PDFp75。工具: プラスドライバー（M.2固定ネジ）。
保守マニュアル第6版にはM.2着脱手順の記載がないため、以下は一般的なM.2 Key M の手順。

1. 空きのM.2スロットを特定する。既存SSDが載っているのがファームウェアSlot 6、空きがSlot 7（ルートポート 0000:2c:03.0）。基板上のシルク印字との対応は未確定なので、**現物で既存SSDがどちらに載っているかを見て、もう一方に装着する**。配置図は `../sources/internal-layout-v62.png`（QuickSpecs p2）。
2. 80mm位置のスタンドオフとネジを確認する。無ければ用意する。
3. SN5100 を約30度の角度でコネクタに差し込み、水平に倒してネジで固定する。片面実装・2.38mm厚なので干渉は少ない。
4. 既存SSDは触らない（OSが入っている）。
5. 起動後、F10 → Advanced → Slot Settings で **M.2 SSDs** が Enabled であることを確認する（既定で有効）。
6. OS起動後、`lsblk -d -o NAME,SIZE,MODEL,TRAN` で 2TB の NVMe が見えることを確認する（番号は `nvme1n1` とは限らず、既存と入れ替わることがある。MODEL列で判別する）。`verify-after.sh` の項目6でリンクが `8.0 GT/s x4` であることを確認する。Gen4ドライブだがこの基板ではGen3接続になる。
7. 用途に応じてパーティション・ファイルシステムを作成する。OSを新SSDへ移す場合は、現在のLUKS+LVM構成の複製（またはクリーンインストール）を別途計画する。本手順書では扱わない。

## 6. GPU（対象外）

RTX 3090（MSI Gaming X Trio）は別の大型筐体機に搭載する方針に変更した。本機はQuadro P2000をSlot 1に残す。電源・カードガイド・筐体寸法の確認は不要。参考情報は [parts.json](parts.json) の `gpu` 項目に残してある。

## 7. 事後処理

1. `bash hardware/replace/verify-after.sh` の出力（`after-<日付>.txt`）を保存する。
2. `../observations.json` を再取得し、`../upgrade-reference.json` / `.txt` の現在構成（CPU、NVMe 2台、M.2空き0）を更新する。
3. `parts.json` の `open_items` を埋め、`verdict` を確定する。
4. 旧CPU（W-2123）は静電袋に入れて保管する。

## 8. トラブル時の切り分け

| 症状 | 確認 |
|---|---|
| 電源が入らない・赤点滅 | ヒートシンクファンケーブルの挿し忘れ、ヒートシンクの締め付け不均等。保守 p41–42/PDFp49–50 |
| POST 008 | BIOSがCPU未対応。BIOS版を確認（保守 p77/PDFp85） |
| POST 912 | クーラーのTDPクラス不一致（保守 p82/PDFp90） |
| メモリ容量が減る・起動しない | DIMMの座り直し。2666表記DIMMとW-2200の組み合わせ（QuickSpecs p14 表）。4章17項 |
| M.2が見えない | BIOS Slot Settings の M.2 SSDs、コネクタの座り、ネジの締め過ぎ |
| CPU温度が高い | グリス塗布量と塗り直し、ファンケーブル、対角締めのやり直し |
